# Ahmed Joy — Developer Portfolio

A responsive, dark modern developer portfolio built with plain HTML, CSS and JavaScript. No build tools or dependencies are required.

## Run locally

Open `index.html` in your browser, or use the VS Code Live Server extension.

## Customize before publishing

Search the project for these starter details and replace them with your own:

- **Email:** replace `hello@example.com` in `index.html` with your real email address.
- **Projects:** replace the three sample project concepts with your real work and add links.
- **Skills:** edit the skill cards to match your actual experience.
- **Social links:** add your LinkedIn, portfolio, and other profile URLs in the footer.
- **About text:** personalize the introduction and location if needed.

## Deploy with GitHub Pages

1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

## Features

- Responsive layout for mobile, tablet and desktop
- Mobile navigation menu
- Animated code-card hero visual
- Skills and project showcase sections
- Scroll progress indicator and reveal animations
- Reduced-motion accessibility support
